De RStudio a VS Code

Lo mínimo para trabajar con R y Python en VS Code, ver dataframes y hacer commits.

1. Instalación 2. R en VS Code 3. Python en VS Code 4. Ver dataframes 5. Git y commits Chuleta

1. Instalación

1
VS Code
code.visualstudio.com, instalación normal.
2
Git
git-scm.com/install, opciones por defecto. Comprueba en la terminal de VS Code (Ctrl+ñ) con git --version.
3
R
cran.r-project.org, igual que para RStudio. Los paquetes ya instalados se mantienen.
4
Python
python.org. Marca "Add Python to PATH" al instalar.
5
Extensiones
Ctrl+Shift+X e instala: R (REditorSupport), Python y Jupyter (Microsoft).
6
Clonar el repositorio
git clone https://github.com/andorra-ri/ari-evicc-etl.git cd ari-evicc-etl code .
Google Cloud y BigQuery es aparte, solo si vas a ejecutar jobs. Está en el manual "Google Cloud + VS Code en proyecto EVICC".

2. R en VS Code R

Abrir consola R

Ctrl+Shift+P, "R: Create R terminal".

Ejecutar código

Cursor en la línea, Ctrl+Enter. Igual que en RStudio.

Ejecutar el script entero

Botón ▷ arriba a la derecha, o Rscript nombre_script.R en terminal.

Ver el Environment

Icono R en la barra lateral. Muestra las variables activas.

La primera vez, acepta instalar el paquete languageserver cuando te lo pida. Da el autocompletado.

3. Python en VS Code Python

ModoCuándoCómo
Script .pyEjecutar de principio a finpython nombre.py
JupyterExplorar paso a paso, como chunks de RStudio# %% antes de un bloque, luego "Run Cell"
# %% import pandas as pd df = pd.read_csv("datos.csv") df.head()

Cada bloque se ejecuta con Ctrl+Enter.

Entorno virtual: si hay requirements.txt, crea uno con python -m venv venv y actívalo con .\venv\Scripts\activate. Luego elige el intérprete arriba a la derecha.

4. Ver dataframes

R Data Viewer

Escribe View(df) en la consola R. Abre tabla con scroll, filtros y orden.

Python Jupyter Variables

Tras ejecutar una celda, Ctrl+Shift+P, "Jupyter: Variables". Doble clic sobre el dataframe.

Nunca se trabaja directo en main. Siempre rama, cambios y Pull Request en Github.

Sin comandos, con el panel Source Control

1
Abre el panel
Ctrl+Shift+G. Lista de archivos cambiados.
2
Añade
Botón "+" sobre el archivo o sobre "Changes".
3
Commit
Mensaje en la caja de arriba, botón ✓.
4
Sync / Push
Botón "Sync Changes" o "Publish Branch".
5
Pull Request
En Github, botón "Compare & pull request" en tu rama.
Antes de cambiar de rama, comprueba con git status que no tienes cambios sin guardar.
